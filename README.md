# Schulorganizer

Ein einfacher Schulorganizer für Lehrkräfte (Stundenplan, Klassen, Noten, Ansagen-Auswertung, Sitzplan, Fortbildungen u. a.).
Alle Daten bleiben auf dem eigenen Gerät – es wird nichts ins Internet gesendet.

## Windows-PC

1. Oben auf **Code → Download ZIP** klicken und die ZIP-Datei entpacken.
2. Einmalig **Python** installieren: <https://www.python.org/downloads/> (beim Installieren **„Add python.exe to PATH“** anhaken).
3. **`Schulorganizer starten.bat`** doppelklicken. Das Programm öffnet sich in einem eigenen Fenster.

Die Daten liegen in `%APPDATA%\Schulorganizer\daten.json`.
Mit **„⬇ Sicherung“** unten im Programm lässt sich jederzeit eine Sicherungsdatei speichern, mit **„⬆ Laden“** wieder einspielen.

## iPad / Browser
